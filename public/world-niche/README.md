# World Niche portfolio preview

Reused from `WorldNiche-Public/apps/web/landing-site/assets`, the source of
https://worldniche.app. The World Niche app and its website are unchanged.

- `app-demo.mp4`: unchanged 13-second silent H.264 recording, 660×1434, 507,405 bytes.
- `app-poster.jpg`: unchanged poster from the real app.
- `hand-phone.webp`: original generated transparent hand/phone frame, resized from
  1024×1536 to 768×1152 and encoded as WebP for the smaller portfolio preview.
  The original screen registration percentages are retained in the CSS module.
